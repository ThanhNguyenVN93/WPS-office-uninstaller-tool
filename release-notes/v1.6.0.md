## v1.6.0 — Trả lại liên kết file cho MS Office & dọn sạch rác WPS / Restore Office file types & remove WPS leftovers

**Mới / New** (chạy trong **CLEAN UP**)
- **Trả lại liên kết file:** máy có **MS Office** thì `.doc/.docx/.xls/.xlsx/.ppt/.pptx/...` (27 loại) mở lại bằng Office, icon trở lại bình thường. Máy **không có Office** thì gỡ liên kết của WPS, Windows trở về trạng thái gốc (lần đầu mở file sẽ hỏi chọn app).
- **Dự phòng:** nếu từ chối quyền admin, vẫn sửa cho user hiện tại. Nếu vẫn còn loại file sai và máy dùng Office Click-to-Run, app đề nghị chạy **Office Quick Repair**.
- **Dọn rác WPS hay sót lại:** scheduled task, mục tự khởi động, mục "WPS Cloud" trong Explorer, menu chuột phải và icon overlay của WPS, service WPS, mục WPS mồ côi trong Programs and Features. Chỉ xoá mục trỏ tới chương trình Kingsoft/WPS.
- **Restore file associations:** with **Microsoft Office** installed, 27 Office types open with Office again and their icons come back. Without Office, WPS's associations are removed and Windows is back to its own state.
- **Fallbacks:** if admin permission is denied, the current user is still fixed. If types are still wrong on Office Click-to-Run, the app offers **Office Quick Repair**.
- **Removes WPS leftovers:** scheduled tasks, autostart entries, the "WPS Cloud" Explorer item, context-menu handlers / overlay icons, services and orphaned uninstall entries (matched by their Kingsoft/WPS program path).

**Lưu ý / Notes**
- CLEAN UP có thêm **một lần hỏi UAC** cho bước này. / CLEAN UP asks for UAC **one more time** for this step.
- Trên Windows 11, liên kết `.pdf` có thể bị Windows khoá; khi đó chọn lại app bằng *Open with > Always*. / On Windows 11 the `.pdf` choice may be locked by Windows; pick the app once with *Open with > Always*.

**Cách cập nhật / How to update**
- Đang dùng v1.5.x: mở app, bấm **Update now**. / On v1.5.x: open the app and press **Update now**.
- Đang dùng v1.4.x trở xuống: tải bản này thủ công một lần. / On v1.4.x or older: download this version manually once.

Cần .NET Framework 4.8 và quyền admin / Requires .NET Framework 4.8 and admin rights.
